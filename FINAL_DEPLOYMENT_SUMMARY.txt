🚀 QUICK START (5 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Access Django Admin
   URL: http://localhost:8000/admin

2. Create Your First Assessment
   Assessments → Add Assessment

3. Add Questions
   Click Assessment → Add Question (repeat 20 times)

4. Publish Assessment
   Assessment Detail → Publish button

5. Enroll Students
   Assessment Detail → Enroll Student

6. Customize Certificate
   Certificate Templates → Add Template → Upload logo

7. Students Can Now Take Exams!
   They see exam in dashboard, click Start, answer, submit
   Get instant results + certificate if passed
